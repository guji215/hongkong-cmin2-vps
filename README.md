## CMIN2 到底是什么，为什么移动用户都在找它

CMIN2（China Mobile International Network 2，AS58807）是中国移动在 2022–2023 年推出的国际精品专线，定位大致相当于电信的 CN2 GIA：独立出海通道，QoS 优先级更高，晚高峰比普通 CMI（AS58453）稳定得多。

背景是这样的：早年买美国 VPS，电信用户跑 CN2 GIA，联通用户走 9929，唯独移动用户绕大弯、丢包，晚高峰体验差一截。CMI 虽然是移动自己的国际线路，但晚高峰拥挤导致掉速的情况不少。CMIN2 出现后，这条专线因为带宽有保障，拥堵问题少了很多。

两个 ASN 的区别很好记：路由里看到 **AS58807 就是 CMIN2**，AS58453 是普通 CMI。用 nextTrace 跑一下回程路由就能确认，不需要任何特殊工具。

以实测数据为例，DC6 机房到北京移动的回程：出洛杉矶后直接打到 223.120.197.1（AS58807 节点），经上海进入国内移动网络，全程约 127ms，CN2 GIA-E 系列晚高峰平均延迟约 158ms、峰值丢包率接近零。这就是“移动用户认准 CMIN2”这件事的实际含金量。
